# 🎵 Music Library Management System

The **Music Library Management System** is a simple project for organizing and managing music files.  
It allows users to add, search, and manage songs, albums, and artists in one place.  

---

## 🚀 Features
- 🎶 Play and manage songs  
- 📂 Organize music by artist, album, or playlist  
- 🔍 Search functionality for quick access  
- 🗄️ Database integration with `music_db.sql`  
- 🌐 Frontend built with **HTML, CSS, JavaScript**  
- ⚙️ Backend powered by **PHP & MySQL**  

---

## 📂 Project Structure
```
├── audio/          # MP3 music files
├── img/            # Album and artist images
├── index.html      # Main homepage
├── playlist.html   # Playlist page
├── search.html     # Music search page
├── app.js          # JavaScript logic
├── style.css       # Stylesheet
├── backend.php     # PHP backend
├── music_db.sql    # Database schema
```
